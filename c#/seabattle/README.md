# Курс основ программирования на МКН СПбГУ
## Проект 2: игра в морской бой

[Постановка задачи](./TASK.md)

Реализована консольная игра для двух игроков "Морской бой". 

### Главное меню:
 1. ***New game***  -- запуск новой игры
 2. ***Exit*** -- выход из игры

### Этапы игры:
1. Расстановка кораблей обоими игроками: вначале первый игрок расставляет свои корабли на карте. Доступно 4 корабля размером 1х1, 3 корабля размером 1х2, 2 корабля размером 1х3 и 1 корабль размером 1х4. Выбрать размер соответсвующего корабля игрок может, нажав клавишу 1-4 на клавиатуре. Далее с помощью  ←, →, ↑, ↓ игрок может передвигать корабль по карте, нажав клавижшу "R" можно повернуть корабль на 90 градусов по часовой стрелке и расположить его на карте, нажав клавишу "Enter". После того, как первый игрок расположил свои корабли, наступает чередь второго игрока.
2. Затем появляются два поля -- поле первого игрока слева и поле второго игрока справа. С помощью  ←, →, ↑, ↓ текущий игрок перемещает курсор по полю и, нажав клавишу "Enter" стреляет по клетке, в которой находится курсор. Если там находится корабль противника или в это поле уже был выстрел, то ход не меняется, если же игрок не попал, то ход переходить к его противнику. В левом верхнем углу отображается количество оставшихся кораблей игрока.
3. Игра завершается, когда все корабли одного из игроков уничтожены.

После окончания игры высвечивается главное меню.
